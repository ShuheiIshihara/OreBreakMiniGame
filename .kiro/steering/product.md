# Product Overview

OreBreakMiniGame - マインクラフト風ダイヤモンド鉱石採掘iOSアプリ

## Core Capabilities

- シンプルなタップ操作で鉱石を採掘
- 3回タップで鉱石が砕ける直感的なゲームプレイ
- 10%のドロップ率でダイヤモンドを獲得
- 経過時間と採掘数の記録・トラッキング
- ビジュアルフィードバック（ヒビ、アニメーション、パーティクル）

## Target Use Cases

- 暇つぶし・リラクゼーション用途
- 短時間での達成感を求めるカジュアルプレイ
- マインクラフトファン向けのカジュアル体験
- タイムアタック・やり込み要素

## Value Proposition

マインクラフトの採掘体験をシンプル化し、運と粘り強さのバランスが生む中毒性のあるゲームプレイを提供。ダイヤモンドドロップまでの時間を競う要素で、リプレイ性を確保。
